# v3.8 升级指南

此版本包含多个 BREAKING CHANGES，建议在升级前仔细阅读以下内容。

## 重点检查

### 运行环境

- 确认 PHP 版本 >= 8.2，否则无法安装此版本

### 简单使用者

- 检查是否有使用微信 `MchTransfer` 相关插件，命名空间已变更为 `Transfer`
- v3.8.0-beta.2 起新增微信小程序虚拟支付支持，如需使用请在 `wechat.default` 配置中增加 `virtual_pay` 节点（offer_id、app_key、callback_token 等）
- v3.8.0-beta.4 起各 Provider 配置校验从 `Pay::config()` 推迟到实际使用该 Provider 时执行，未使用的 Provider 配置不完整不再导致初始化报错
- v3.8.0-beta.4 起微信虚拟支付客户端签名自动对 signData 做字典序排序，并在返回结果中提供与签名逐字节一致的 `signData` JSON 字符串，前端请原样传递给 `wx.requestVirtualPayment`
- v3.8.0-beta.4 起微信虚拟支付服务端 API 支持配置 `virtual_pay.app_secret` 自动获取并缓存 access_token（stable_token 接口）
- v3.8.0-beta.5 起依赖要求变更为 `yansongda/artful ~1.2.0`、`yansongda/supports ~4.1.0`（Composer 安装时自动处理）
- v3.8.0-beta.5 起所有 Provider 配置统一校验 `mode` 合法性，非法值直接抛出 `InvalidConfigException`（此前为 warning 或静默回退）；江苏银行不支持服务商模式（`MODE_SERVICE`），传入将被拒绝
- v3.8.0-beta.5 修复 PayPal 请求 body 残留业务参数的问题（查询/捕获/退款请求不再混入 `order_id`、`refund_id` 等业务标识参数），PayPal 回调验签前置校验扩展至全部 transmission/cert/algo 请求头（#1196）
- v3.8.0-beta.5 修复 Stripe 查询/取消/退款查询接口因请求残留内部参数而实际不可用的问题；Stripe 支付缺必要参数时改为 SDK 侧直接抛出异常；新增支持通过 `_headers` 参数注入自定义请求头（如 `Idempotency-Key`、`Stripe-Version`、`Stripe-Account`）

### 自有插件开发者

- 检查是否有自行扩展相关插件，如果有，请对照 `breaking changes` 检查是否需要更改
- 所有 Plugin 已迁移使用 Trait 方法代替 `Functions.php` 函数调用
- v3.8.0-beta.3 起所有 Provider 的 `_url` payload 字段统一为前导 `/` 格式，各 Provider 的 base URL 常量已去掉尾部 `/`。如自定义插件中设置了 `_url` 字段，请遵循前导 `/` 约定（例如 `/v3/pay/transactions/native` 而非 `v3/pay/transactions/native`）
- v3.8.0-beta.5 起 src 内 provider 名称 100% 常量化，统一引用 `Pay::PROVIDER_*` 常量；`Config` 的 Provider 配置类映射与 `AbstractServiceProvider` 改为静态实例化，自定义 ServiceProvider 或扩展 Provider 映射时请留意（#1193、#1194）

## 更改版本号

将 composer.json 的 yansongda/pay 版本号更改为 `~3.8.0`，随后 `composer update` 即可。

### BREAKING CHANGES

- change: 最低 PHP 版本要求从 8.0 升级到 8.2 (#1139)
- change: 所有 Provider 配置统一校验 `mode` 合法性，非法值由原来的 warning / 静默回退改为抛出 `InvalidConfigException(CONFIG_PROVIDER_INVALID)`；江苏银行不再接受服务商模式 `MODE_SERVICE` (#1197)
- delete: 移除废弃函数 `get_alipay_config`、`get_wechat_config`、`get_unipay_config`，请使用 `get_provider_config` 代替 (#1139)
- delete: 移除废弃的 `Wechat\StartPlugin`，请使用 `Yansongda\Artful\Plugin\StartPlugin` 代替 (#1139)
- delete: 移除废弃的微信 Transfer 插件（因微信支付 API 变更）(#1139)
- change: 重命名 `MchTransfer` 命名空间为 `Transfer` (#1139)
- delete: 删除 `src/Functions.php` 文件，所有辅助函数已迁移到对应的 Trait (#1142, #1143, #1144)
